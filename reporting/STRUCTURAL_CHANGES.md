# Reporting Structural Change Tags

The following tags capture major reporting and governance adjustments that must
be tracked for upcoming releases. Each tag should be referenced in PR titles and
release notes when the associated work lands.

- **release-0.3/reporting-ledger** – Promote compute/carbon ledgers to mandatory
  report artefacts to satisfy the October 2025 TMLR compliance bulletin.
- **release-0.3/reporting-governance** – Cross-link dataset provenance manifests
  with generated reporting bundles so audit trails survive future pipeline
  updates.
