# Data Card

## Overview

This project trains reinforcement learning agents on synthetic and historical lead-lag signature datasets derived from
financial time series. The core objective is to model relative price movements between paired assets while respecting
regulatory and anonymisation requirements.

## Datasets

- **Synthetic regimes:** Generated via controlled stochastic processes that vary volatility, correlation, and market
  regimes. These runs supply stress scenarios for risk-aware evaluation.
- **Historical lead-lag pairs:** Curated from public equities and futures data released under permissive vendor terms.
  Identifying metadata (tickers, venues) is masked through hashing so reviewers cannot reconstruct proprietary feeds.
- **Offline replay buffers:** Logged from prior on-policy experiments and stored as trajectory CSVs. They capture
  observation, action, and reward tuples for offline baselines.

Each dataset ships with a manifest (see `preprocessing_data/manifests/`) that records provenance, date ranges, and hash
sums for integrity checks.

## Licensing and Terms of Use

- Synthetic data is licensed under the repository’s primary license (Apache-2.0) because it is fully generated by the
  authors.
- Historical snippets rely on vendor feeds that permit redistribution for research and review when individual symbols
  remain anonymised. Reviewers must not attempt deanonymisation or merge the hashes with external symbol dictionaries.
- Offline buffers inherit the licensing of the runs that produced them; all originate from the synthetic or anonymised
  historical data above.

Users may reproduce the preprocessing pipeline locally but should confirm downstream usage complies with their
institution’s data-handling policies.

## Split Policy

- **Training:** Combines synthetic regimes with 70% of the anonymised historical windows.
- **Validation:** 15% stratified sample of historical windows plus targeted synthetic stress cases.
- **Test:** Remaining 15% of historical windows held out chronologically to mimic live deployment. Replay buffers drawn
  from prior experiments never include trajectories from the test windows.

Temporal splits avoid leakage by respecting chronological order within each asset pair. Synthetic datasets are versioned
by scenario identifiers so they can be regenerated deterministically.

## Preprocessing and Quality Checks

- Normalisation of price differentials and volume features per window.
- Lead-lag signature extraction via `preprocessing_data/signature_pipeline.py` using truncated log-signatures.
- Outlier detection leveraging median absolute deviation thresholds per feature group.
- Automated governance script (`preprocessing_data/validate_manifests.py`) verifying schema, hashes, and licence notes.

Quality reports are stored under `results/data_quality/` with timestamped summaries of any anomalies.

## Usage Notes

- Do not combine anonymised windows with external metadata to infer the underlying instruments.
- Respect the replay buffer schema when extending the offline datasets; altered columns invalidate downstream loaders.
- Cite this data card alongside the model card when distributing derivative work or replication packages.
